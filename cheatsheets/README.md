### Hosting de aplicaciones <a name="hosting"></a> 

- :classical_building: [Vercel]() - Despliegue optimizado con un solo clic para aplicaciones Frontend, frameworks modernos (Next.js, Angular, React) y arquitecturas Serverless.
- :classical_building: [Netlify]() - Plataforma integral de automatización para la web moderna que gestiona compilaciones, funciones serverless y hosting Jamstack global.
- :classical_building: [Render]() - Alternativa en la nube para desplegar aplicaciones Backend escritas en Express, FastAPI, bases de datos y webs estáticas sin configuraciones complejas.
- :classical_building: [FastAPI Cloud](https://dashboard.fastapicloud.com/login?redirect=%2F) - Entorno en la nube especializado y preconfigurado para el aprovisionamiento instantáneo de microservicios con FastAPI.
- :classical_building: [Superbase](https://supabase.com/) - La alternativa de código abierto a Firebase que te proporciona base de datos PostgreSQL en tiempo real, autenticación, almacenamiento de archivos y funciones Edge.
- :classical_building: [Firebase]() - Plataforma madura de Google que centraliza bases de datos NoSQL, autenticación nativa, hosting y analíticas en un ecosistema integrado.
- :classical_building: [Neon](https://neon.com/) - Servidor de bases de datos PostgreSQL serverless con escalado a cero instantáneo y capacidades avanzadas de branching de datos para desarrollo.
- :classical_building: [Xata](https://lite.xata.io/) - Base de datos PostgreSQL serverless con una interfaz amigable e intuitiva estilo hoja de cálculo y motor de búsqueda de texto completo integrado.
- :classical_building: [Cockrachlabs](https://www.cockroachlabs.com/) - Base de datos SQL distribuida de arquitectura nativa en la nube (Cloud-Native), diseñada para una consistencia de datos indestructible y alta disponibilidad global.
- :classical_building: [MongoDB Atlas](https://account.mongodb.com/account/login?nds=true) - Base de datos NoSQL documental gestionada en la nube con herramientas integradas de analítica, búsqueda vectorial y escalado global automatizado.
- :classical_building: [Turso](https://turso.tech/) - Base de datos relacional distribuida basada en libSQL (fork de SQLite) optimizada para tiempos de respuesta ultra bajos y arquitecturas en el borde (Edge).
- :classical_building: [Dokploy](https://dokploy.com/) - Panel de control autohospedado para administrar tus propios servidores VPS mediante Docker, actuando como tu propio Heroku o Render privado.
- :classical_building: [Zeabur](https://zeabur.com/es-ES/) - Hosting global automatizado multilenjuaje y multiframework que despliega servicios frontend, backend y bases de datos con cero fricción de infraestructura.
- :classical_building: [Koyeb](https://www.koyeb.com/) - Plataforma de despliegue serverless de alto rendimiento que corre tus contenedores Docker globalmente en milisegundos con soporte nativo de microservicios.
- :classical_building: [Northflank](https://northflank.com/) - Plataforma para desarrolladores que permite compilar, desplegar y escalar aplicaciones backend, microservicios, tareas programadas y bases de datos (ofrece un nivel de entrada con dos servicios gratuitos).
